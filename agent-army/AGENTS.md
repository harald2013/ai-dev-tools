# AGENTS.md — agent-army

Produktive Agents. Jeder Agent loest eine echte, benannte Aufgabe.

## Regeln

- **Kein Uebungscode.** Was nur der Veranschaulichung dient, gehoert nicht in
  dieses Verzeichnis.
- **Jeder Agent bringt mit:** was er tut, was er anfassen darf, wo seine
  Grenze liegt (Permissions/Tools), und eine Kostenbremse (`max_turns`,
  `max_budget_usd` o. ae.).
- **Kein ungefragter Schreibzugriff** auf Verzeichnisse ausserhalb des
  jeweiligen Agent-Verzeichnisses.
- Zugangsdaten kommen aus der Umgebung, nie aus dem Code und nie ins Repo.
